# MAKET 296 STUDIO — Qt 6 Windows

Нативный фоторедактор на C++ / Qt 6. Ширина макета 296 мм, экспорт PDF, PNG и SVG.

## Получить Windows EXE через GitHub Actions

1. Скачайте архив исходников `MAKET_296_QT6_АВТОСБОРКА_WINDOWS.zip` из чата ChatGPT.
2. [Откройте страницу загрузки](https://github.com/khomutovmailbox-oss/MAKET-296-STUDIO/upload/main).
3. Загрузите **ZIP без распаковки**, сохранив имя `MAKET_296_QT6_АВТОСБОРКА_WINDOWS.zip`, затем нажмите **Commit changes**.
4. [Перейдите во вкладку Actions](https://github.com/khomutovmailbox-oss/MAKET-296-STUDIO/actions). Сборка начнётся после коммита автоматически, либо запустите workflow **Build MAKET 296 — Qt 6 Windows** вручную.
5. После успешной сборки откройте запуск и скачайте **Artifacts → MAKET_296_QT6_Windows**.
6. Распакуйте скачанный архив полностью и запустите `MAKET_296_QT6.exe`. Соседние DLL Qt обязательны.

Пока архив не загружен и сборка не завершена, исполняемого файла в репозитории нет. Во время сборки выполняются проверки экспорта PDF, PNG и SVG, формата 296 мм и прозрачности PNG.

Проект: пустые фотообласти, фотографии без зазоров, отсутствие фона, отдельный режим фото-букв. LOVE как отдельного шаблона нет.
