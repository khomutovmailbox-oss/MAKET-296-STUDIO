# MAKET 296 STUDIO — Qt 6

Нативный редактор макетов шириной 296 мм. Экспорт PDF, PNG и SVG. Фон страницы прозрачный.

## Редактирование фото

- **+ Загрузить несколько фото** — заполнить штатные фотообласти шаблона.
- **+ Фото поверх макета** — добавить свободные фотообъекты; их можно перемещать, менять размер и накладывать друг на друга.
- В обычном режиме перетаскивай фото за рамку; нижний правый маркер меняет ширину и высоту.
- **Обрезка** — перетаскивай изображение внутри рамки, колесом мыши меняй масштаб. «Сбросить» возвращает исходное кадрирование.
- Ctrl+клик выделяет несколько фото. На вкладке **Слои** можно выделить несколько объектов списком. Если декор перекрывает фото, Alt+клик выбирает фото под ним.
- В блоке «Одинаковый размер» кнопки **Высоту всем** и **Ширину всем** задают одну и ту же высоту/ширину каждому выделенному объекту, сохраняя его пропорции.
- Поля X / Y / ширина / высота задают геометрию в миллиметрах. Для группы это общий габарит группы.
- «Выше» и «Ниже» меняют порядок наложения. Блокировка защищает объект от перемещения и изменения размера.

## Редактирование декора

Вкладка **Слои** содержит фото и отдельные векторные элементы исходного PDF. Каждый векторный элемент можно выбрать, переместить, изменить размер, цвет и непрозрачность, скрыть, заблокировать, удалить или переставить относительно других векторных элементов.

Текст, преобразованный исходным PDF в кривые, остаётся векторным контуром. Чтобы заменить его содержимое: скрой/удали исходный контур, нажми **+ Добавить надпись**, затем отредактируй текст в панели свойств. Новые надписи сохраняются как редактируемые объекты.

## DTF и экспорт

- PNG — прозрачный RGBA, sRGB, 300 dpi.
- PDF и SVG сохраняют векторный декор.
- Перед PDF/PNG программа предупреждает о пустых фотообластях и фотографиях, которые после кадрирования/масштабирования дают меньше 300 dpi.
- Итоговое качество и белая подложка дополнительно зависят от исходных фото и RIP-настроек конкретного DTF-производства.

## Сборка Windows

GitHub Actions использует исходный архив MAKET_296_QT6_EXACT_SOURCE.zip, применяет редакторский патч и собирает автономный комплект Qt 6. Готовый архив находится в **Actions → последний успешный запуск → Artifacts**. Распаковывай комплект целиком; не отделяй EXE от DLL и папки platforms.
