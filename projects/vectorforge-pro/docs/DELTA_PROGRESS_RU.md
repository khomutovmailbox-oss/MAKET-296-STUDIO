# VectorForge Pro — частичные обновления документа

Завершена локальная реализация C++20 команды `delta(page, since)` и Python клиента, который строго проверяет ревизии, IDs объектов, страницу и порядок слоёв. **Полные исходники этих изменений находятся в исходном ZIP**, а не в текущем PR.

## Новый протокол
- `state(page)`: полный снимок для синхронизации
- `delta(page,since)`: `upsert`, `removed`, опциональные `order` и `metadata`
- `reset:true`: полный снимок, если клиент пропустил ревизию
- Неизменённые C++ JSON-объекты не копируются повторно в кэше протокола
- Tk не запускает экспорт/растеризацию активной страницы при сохранении или редактировании другой страницы

## Проверки
16/16 C++ CTest, 34 теста импорта, 19 Python тестов редактора, 9 GUI-сценариев (Linux Xvfb).

Синтетический документ: 5 страниц / 3250 фигур, Linux C++ Release, 60 запросов:
| Запрос | Медиана | JSON |
|---|---:|---:|
| Вся страница (650 фигур) | 2,132 мс | 108264 байта |
| Изменение одной фигуры | 0,576 мс | 297 байт |
| Нет изменений | 0,031 мс | 133 байта |

Это **3,7×** для одной IPC-операции и **99,73%** меньше трафика. Не утверждается ускорение всей программы.

## Безопасность
Ветка не меняет существующую сборку MAKET-296 и не затрагивает чужие проекты. Для полноценного CI исходники необходимо распаковать из ZIP **в `projects/vectorforge-pro/`**. Не загружать ZIP как единственный файл: GitHub Actions не извлечёт его автоматически.
