# Ускорение обмена C++ → интерфейс

Проверенные изменения: новая команда `status`, выборка `state(page=...)`, перерисовка только временных элементов при изменении выделения.

## Измерения

Linux C++ Release, 3250 прямоугольников, 5 страниц, 650 объектов на каждой; 60 последовательных запросов.

| Режим | Медиана | p95 | Размер ответа |
|---|---:|---:|---:|
| Полный `state` | 7,050 мс | 9,371 мс | 509 676 байт |
| `state(page)` | 1,515 мс | 2,829 мс | 127 746 байт |
| `status` | 0,019 мс | 0,077 мс | 49 байт |

Ускорение передачи активной страницы ~4,65×, не всей программы. На Windows не измерено.

## Что проверено

- 16/16 наборов CTest рабочей C++-сборки.
- Чистая сборка `vforge_live_editor` из отдельного ZIP.
- 15 Python интеграционных тестов, включая проверку обратной совместимости старой команды `state`.
- GUI smoke tests для canvas overlay и масок.
- Формат .vforge без изменений, схема 9.

Полный исходный код содержится в локальном архиве; в GitHub на этой ветке сейчас выложен патч `patches/page_scoped_state.patch`, но не вся кодовая база.
