# Встроенный CPU-композитор для SVG-масок и смешивания

В текущем локальном исходном ZIP доступен `studio/fx_compositor.py`: CairoSVG/Cairo растрирует геометрию, Pillow+NumPy компонуют альфа-маски и blend modes. Это **внутрипроцессный CPU-рендерер**, не GPU и не отдельный Windows EXE. Поддерживается ограниченный поднабор SVG, который выдаёт собственный C++-экспортёр VectorForge.

Поддержаны raster PNG alpha masks, vector clipPath, normal/multiply/screen/overlay/darken/lighten/difference, базовые коррекции яркости/контраста/насыщенности. Неизвестные SVG эффекты вызывают явный fallback на Inkscape (если есть), а не молчаливую потерю эффекта. Оригинальные ассеты и формат .vforge не меняются.

## Измерение (Linux, один макет 1000 × 700)
- In-process после оптимизации прямоугольников и изображений: **181,45 мс** (медиана 12 итераций)
- Внешний Inkscape CLI: **318,32 мс** (медиана 7 итераций)
- ~**1,75×** в одном тесте именно визуального предпросмотра; не показатель всей программы
- Сравнение с эталоном вне текстовых областей: средняя абсолютная ошибка 0,00028 на цветовой канал из 255, максимум 1/255. Шрифт Cairo/Inkscape может отличаться заметнее.

## Проверено
31 Python-тест редактора, 34 теста импорта, 16 нативных CTest на неизменённом C++-исходнике из предыдущей сборки, C++ редактор независимо пересобран из чистых исходников; реальный GUI открывает маски при отключённой доступности Inkscape. Старые GUI проверки кеша и выбора объектов также прошли.
