# VectorForge Pro — испытание трассировки двух реальных макетов

Дата: 6 ноября 2026. Контрольные исходники: «Дорожные звёзды» JPEG 1254×1254 и «Король рыбалки» PNG RGBA 2048×810. Оригиналы в репозиторий не загружались.

## Результат
Для сложной иллюстрации с бликами, градиентами, золотой фактурой и декоративным шрифтом нельзя честно обещать идеальный чистый вектор из одной цветовой сегментации. Подготовлены два разделённых результата:

- HYBRID MASTER SVG: оригинал встроен lossless, векторная трассировка находится в отдельном нижнем слое. На белом фоне Inkscape render совпал с исходником пиксель-в-пиксель (max diff 0, mean diff 0, 0 отличающихся пикселей).
- VECTOR ONLY SVG/VFORGE: редактируемые контуры, но это аппроксимация; градиентные сетки, исходный шрифт и золотая гравировка не восстановлены.

## Сбалансированный сглаженный профиль
24 цвета, min region 32 px, simplify 1.2 px, Bezier smoothing включён. Cleanup: 6 проходов для JPEG и 4 для золотой надписи.

## Проверки
- Полная чистая CMake/Ninja Release-сборка из распакованного source ZIP: успешна.
- CTest 16/16; Python 46/46; реальный Tk + C++ JPEG trace smoke прошёл.
- C++ color trace suite: 48 проверок, включая Bezier smoothing.
- Оба reference .vforge открыты нативным C++ editor как один заблокированный image object.
- Hybrid SVG рендерится в Inkscape с точным совпадением на белом фоне.
- Windows, CorelDRAW, Illustrator, CMYK/ICC и физическая печать отдельно не тестировались.

## Важно
Векторный слой в HYBRID MASTER скрыт визуально белой подложкой и исходным изображением, но остаётся отдельным редактируемым слоем. Чтобы увидеть его, выключите слои «01 — Оригинал» и «02 — Белая подложка». В VectorForge открывайте REFERENCE.vforge или VECTOR_ONLY.vforge: текущий SVG-импортёр ещё не импортирует embedded image + multi-subpath hybrid.
