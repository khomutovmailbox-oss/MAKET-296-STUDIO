# Ускорение выбора объектов — VectorForge Pro

Реализован `studio/spatial_index.py`: ограниченный пространственный индекс активной страницы. Сохраняет порядок наложения и геометрию выделения, учитывает скрытые слои, эллипсы и группировку. Крупные объекты хранятся в отдельном списке, чтобы не создавать слишком много клеток.

Изменённый `studio/studio.py` и `studio/delta_state.py` находятся **в полном локальном ZIP**, а в PR лежит интеграционный патч `patches/spatial_selection.patch`. Полный исходный код остального редактора всё ещё нужно добавить в эту ветку, прежде чем заработает CI.

## Проверка производительности

Linux Python; 40 000 прямоугольников, 600 кликов в случайных координатах, без общей отрисовки и C++ IPC:

- Старый перебор: медиана **4,0503 мс**, p95 **7,51523 мс**
- Индексированный выбор: медиана **0,01081 мс**, p95 **0,01723 мс**
- Построение индекса: **91,527 мс** (однократно на состояние страницы)
- Разворачивание групп: медиана **0,00641 мс**
- Медианное ускорение *только hit-test*: **374,8×**. Нельзя распространять на скорость всей программы.

Проверки: 16 C++ тестов, 23 Python теста UI, 34 теста импорта, GUI сценарии выбора, Undo/Redo, кривых Безье, группировки, булевой геометрии и масок. Это результаты локального Linux; Windows CI на GitHub не запускался.

## Установка

В ZIP файлы лежат в `projects/vectorforge-pro/`. Нужно распаковать их в *ветку* `feature/vectorforge-bootstrap`, не в корень существующего MAKET-296 проекта и не в `main`.

Код: `studio/spatial_index.py`; тесты: `studio/tests/test_spatial_index.py`, `studio/tests/gui_spatial_smoke.py`, `studio/bench_spatial_index.py`. Исполняемый Windows EXE пока не выпускается.
