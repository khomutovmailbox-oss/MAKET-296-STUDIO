# VectorForge Pro — отдельный проект

Здесь развивается **VectorForge Pro**, независимый профессиональный графический редактор Windows: единый документ с вектором, растром и трассировкой.

**Это не проект MAKET-296**. Его исходники, сборка и формат документов не должны смешиваться с другими приложениями в этом репозитории.

## Текущий статус

- Последний локальный исходный срез: **Studio M16** (C++20 + промежуточный Tk-интерфейс).
- Нативный Windows GUI / полноценный импорт CDR и AI **не подтверждены**.
- Архив с исходниками **ещё не загружен в эту папку**.
- После размещения кода с `CMakeLists.txt` в этой папке запустится изолированный CI `vectorforge-ci.yml`.

## Структура

```
projects/vectorforge-pro/
  CMakeLists.txt
  include/
  src/
  studio/
  tests/
  compat/
```

**Не копировать** содержимое VectorForge в корень репозитория, чтобы не изменить существующую сборку MAKET 296.

## Главные критерии

1. Сохранение и открытие `.vforge` без потерь, безопасные миграции и резервные копии.
2. Быстрая отзывчивость интерфейса, тяжёлые операции в фоне; замеры с тестовыми сценариями.
3. Отдельные редактируемые векторные и растровые объекты, маски, слои, трассировка.
4. Реальная, проверяемая совместимость CDR/AI/PDF/SVG; при неполном импорте явное предупреждение.
5. Никакого автоматического слияния в `main` без успешных тестов и проверки изменений.

Сборку Windows EXE по текущему решению откладываем до готовности функций редактора.
